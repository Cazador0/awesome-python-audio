# Skills

Operational skills for MDS agents. Each note states **when to use it**, the
**inputs/outputs**, and the exact ACE-Step `task_type` + key parameters, so an agent can
act from the note alone.

- [[stem-separation]] — pull stems out of existing audio (`extract`)
- [[stem-regeneration]] — re-render one stem or window without touching the rest (`repaint`, `lego`)
- [[prompt-translation]] — compile prompts into SongBlueprint → StemSpec (`text2music`)
- [[best-of-n-evaluation]] — score N candidates and gate on acceptance thresholds

Related: [[acestep-api]] for the wire contract, [[stem-engineering]] for what a *good*
stem is, [[glossary]] for terms.
